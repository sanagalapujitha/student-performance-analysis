# 📊 Student Performance Analysis

> A comprehensive Exploratory Data Analysis (EDA) project that examines factors influencing student academic performance using Python and data visualization techniques.

---

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Student Performance dataset to understand the dataset structure, evaluate data quality, analyze statistical properties, and identify patterns that influence students' final academic performance.

The analysis includes data cleaning, statistical analysis, outlier detection, correlation analysis, and data visualization to generate meaningful insights that can support future predictive modeling.

---

## 🎯 Objectives

- Import and inspect the dataset
- Explore dataset structure and features
- Perform descriptive statistical analysis
- Identify and handle missing values
- Detect and remove outliers
- Analyze relationships between variables
- Create meaningful visualizations
- Generate key insights from the data

---

## 📂 Dataset Information

The dataset contains information related to student demographics, study habits, and academic performance.
Dataset link - <https://www.kaggle.com/datasets/devansodariya/student-performance-data>

### Sample Features

- Gender
- Age
- Study Time
- Failures
- Absences
- First Period Grade (G1)
- Second Period Grade (G2)
- Final Grade (G3)

## ▶️ How to Run

### Clone the repository

```bash
git clone https://github.com/your-username/Student-Performance-Analysis.git
```

### Navigate to the project directory

```bash
cd Student-Performance-Analysis
```

### Install required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

or open the notebook directly in **Google Colab**.
